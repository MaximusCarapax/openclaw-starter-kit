# HEARTBEAT.md

Your heartbeat runs periodically (default: every hour). Define what you check and when to alert.

## Checks to Run

Add your regular checks here:

- [ ] Check for important emails
- [ ] Review calendar for upcoming events (next 24h)
- [ ] Check task list for overdue items
- [ ] Monitor any background processes

## When to Alert Your Human

Only interrupt when it matters:

- Urgent emails from important contacts
- Meetings starting within 2 hours
- Overdue high-priority tasks
- Something requiring immediate attention

## When to Stay Silent (HEARTBEAT_OK)

- Late night (23:00-08:00) unless truly urgent
- Nothing new since last check
- Just checked less than 30 minutes ago
- Human is in a meeting or clearly busy

## Background Work (Chief of Staff Mode)

If operating in proactive mode, heartbeats can also:

- Review and organize memory files
- Update MEMORY.md with insights from recent conversations
- Check on long-running tasks
- Prepare daily briefings
- Generate ideas (if idea cron not set up separately)
